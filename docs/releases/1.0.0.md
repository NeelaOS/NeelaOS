# NeelaOS 1.0.0

*OS, for the love of wind*

The first release of NeelaOS: a free, Windows-familiar Linux desktop for Computer Science
students, with every coding tool ready from the very first boot. Built on Fedora 44 and
KDE Plasma 6.

## Highlights

- **Feels like Windows.** Start button, taskbar, desktop icons, `Win` key shortcuts, and a
  **Files** app laid out like File Explorer, with Quick access, Network and This PC.
  Apps have plain names: Files, Terminal, Notepad, Task Manager, Snipping Tool.
- **Ready to code.** C/C++, Python, Java, Node.js, SQLite, Git and Podman out of the box.
  VS Code arrives on first boot with the right extensions. **`sudo apt install`** works like
  on Ubuntu, Ubuntu package names included.
- **rgit built in.** Everyday Git in one command: `rgit push "message"`, `rgit pull`, `rgit undo`.
- **Dev packs.** One click in the Welcome app sets up Web Development, Data Science & AI,
  Competitive Programming, Android, Networking & Security and more.
- **Safe to experiment.** Restore points before every update and once a day, like Windows
  System Restore.
- **Updates in one place.** Fedora, NeelaOS, Brave and VS Code updates arrive together in
  Neela Store, or with `sudo apt update && sudo apt upgrade`.
- **Made to look good.** Neela Dark and Neela Light themes, six original wallpapers, a NeelaOS
  boot menu, splash, login screen and installer (**Neela Setup**), and the *Digital Dawn*
  startup sound.

## System requirements

- 64-bit PC (Intel or AMD), **4 GB RAM** (8 GB recommended)
- **40 GB** of disk space
- A USB stick of 8 GB or more, to install from
- Internet during the first login (VS Code, Brave and codecs are downloaded then)
- Secure Boot supported

## Install

1. Write the ISO to a USB stick with **Rufus** (*DD image mode*), **Fedora Media Writer** or **balenaEtcher**.
2. Boot from the USB (usually `F12`, `F11`, `F9`, `Esc` or `F2` at startup) and choose **Start NeelaOS**.
3. Try it live, then click **Install NeelaOS**. Neela Setup asks for your language, keyboard,
   disk (whole disk, or alongside Windows) and account.
4. Restart, remove the USB and log in. Stay online for 10–20 minutes while setup finishes.

## Known limitations

- **Windows-only programs** (Microsoft Office desktop, Adobe apps, games with anti-cheat) don't
  run. Use LibreOffice or Office online; many Windows games work through Steam's Proton, and the
  *Run Windows Programs* dev pack runs many simple `.exe` programs.
- **Ubuntu `.deb` files** can't be installed. Use Neela Store or the app's `.rpm` version.
- **The live USB has no visible web browser.** Brave is installed on first boot of the installed system.
- **First boot needs internet** to finish setting up VS Code, Brave and codecs. Without it, setup
  retries automatically once you connect.
- In **Files**, the window title ends in "Dolphin" (the app NeelaOS's Files is built on), and
  desktop shortcuts appear with their file names (e.g. `brave.desktop`) when you open the
  Desktop folder there. They look normal on the desktop itself.
- Installing in a virtual machine with 1 CPU is very slow; give it 2–4 CPUs.

## Updating

```bash
sudo apt update && sudo apt upgrade
```

or **Neela Store → Updates**. A restore point is taken before every update.
